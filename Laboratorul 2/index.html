Partea 1 – Republica Moldova

Republica Moldova este o țară din Europa de Est, situată între România și Ucraina. Capitala și cel mai mare oraș este Chișinău. Limba oficială este româna, iar forma de guvernământ este o republică parlamentară unitară.

Obiective turistice

  • Orheiul Vechi
  • Cetatea Soroca
  • Vinăria Cricova
  • Mănăstirea Căpriana
  • Castel Mimi

Partea 2 – Norvegia

Norvegia este o țară din Europa de Nord, situată în partea de vest a Peninsulei Scandinave. Capitala și cel mai mare oraș este Oslo. Norvegia este o monarhie constituțională și are două limbi oficiale, norvegiana și sami.

Activități pentru turiști

  1. Explorarea fiordurilor norvegiene
  2. Vizitarea orașului Oslo
  3. Observarea aurorei boreale
  4. Drumeții în munți
  5. Plimbări cu vaporul

Partea 3 – Suedia

Suedia este o țară din Europa de Nord, situată în Peninsula Scandinavă. Capitala și cel mai mare oraș este Stockholm. Suedia este o monarhie constituțională parlamentară și are suedeza ca limbă oficială.

Termeni asociați Suediei

Stockholm
Capitala și cel mai mare oraș al Suediei.
IKEA
Companie suedeză cunoscută pentru mobilier și produse pentru casă.
Volvo
Marcă suedeză cunoscută pentru automobile și vehicule.
ABBA
Grup muzical suedez celebru la nivel internațional.
